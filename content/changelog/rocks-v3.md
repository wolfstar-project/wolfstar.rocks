The v3 dashboard shipped with WolfStar v7, in [release v0.16.0](https://github.com/wolfstar-project/wolfstar.rocks/releases/tag/v0.16.0):

- **One dashboard page.** Everything is at `/app`: a rail of servers, a sidebar of sections, a bar at the bottom of the screen on phones, and one bar that holds the changes you have not saved yet. Old `/guilds/…` links still open the right server and section.
- **Built on WolfStar v7's settings.** The dashboard reads and writes the same settings as the bot, in the same shape, so a change made in one is the change the other sees.
- **A section for each part of the bot.** Moderation, Auto Moderation, Honeypot, Join Guard, Appeals, Auto-Delete, Auto-Purge, Auto-Message, Commands and Dashboard access. Auto-moderation rules are edited one by one and saved as soon as they change.
- **Logs in one place.** Moderation history, warnings, command history and settings activity, each a table you can page through.
- **A redrawn site.** New header and footer, new WolfStar and Staryl pages, a rebuilt commands list, and colour themes that follow Discord's, a custom one included.
- **The whole site in Italian.** The [translation status](/translation-status) shows how far each other language has come.
